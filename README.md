## Hi there 👋

💻 I'm Alexey — an **AI Engineer from Saint Petersburg** working on **LLMs, RAG, and agentic systems**.

💼 At **ITMO Industrial Research Lab** I build a multi-agent assistant for enterprise document search and process automation — designing the agents, the tools they call, and the orchestration that holds them together.

Most of my work sits on three layers. **Agents:** for example, a CodeAct sub-agent for tabular analytics that generates pandas code for deterministic operations and falls back to LLM calls for semantic ones; a deep file-processing agent that chunks documents structurally and traverses them in map-reduce or refine mode. **Tools:** the retrieval, parsing, and data-access layer those agents run on. **Orchestration:** routing between agents, handling state across multi-step tasks, and keeping the system predictable when a step fails.

I also built an evaluation benchmark for AI agents working with tabular data — without it there's no way to tell whether a change to the pipeline actually helped. Earlier I developed an uplift-analysis agent that calls statistical methods as tools and grounds its explanations in RAG, causal graphs, and propensity score matching.
